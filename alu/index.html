Encrypt: light vs silicon The idea

A 4-bit calculator built from light

Four copies of the optical full adder from the paper sit on one silicon chip. Each bit adds by interference: two Michelson XORs and a carry read from four photodiodes. The bits are chained electronically: a comparator reads each carry and sets the next bit's carry-in heater. Every answer below comes from the simulated light levels of the drawn chip, one circuit per bit, extracted from the KLayout layout.

Inside the chip, bit by bit

Read right to left, like the number: bit 0 works first and hands its carry to bit 1. Bars are photocurrents from the simulation; the amber tick is that bit's comparator threshold. The highlighted reading is the one this operation uses.

Every operation, on this chip

All 1,536 operations: ADD with both carry-ins, SUB, AND, OR and XOR, each over all 256 pairs of A and B, with detector noise at the laser power above.

How one chip does five operations

  • ADD: the carry ripples from bit 0 to bit 3.
  • SUB: the heater driver inverts B and sets the first carry to 1, so A − B = A + not B + 1.
  • AND, OR: each bit's carry output is a majority vote of A, B and carry-in. With carry-in 0 that is A AND B; with carry-in 1 it is A OR B.
  • XOR: read each bit's first Michelson directly.

Why calibration matters

Heaters are the only thing that can be adjusted on this passive chip, so each bit is tuned after fabrication using only its own grating-coupler readings. Pick Stressed, uncalibrated above: with the nominal settings, bit 2's XOR level sinks below the shared threshold, the wrong X spoils its SUM, and 732 of 1,536 operations fail. Calibrate each bit and the same die makes no mistakes.

What is real here

The layout passes the foundry's checks. The light levels come from a circuit simulation of each bit using the design kit's component models, with drawn waveguide lengths and back-reflections. The comparators and heater drivers are modelled, not drawn. Thermal heaters switch in tens of microseconds, so this chip shows the logic, not speed; for how fast the light itself computes, see the encryption page.
